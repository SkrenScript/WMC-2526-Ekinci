# Film-Finder

Schulprojekt von Toprak Ekinci.

## Konzept

Die Website sucht Serien und Filme ueber die TVMaze API. Dazu gibt es eine eigene Watchlist-Seite.

## Erfuellte Vorgaben

- client-side JavaScript
- `fetch` wird verwendet
- DOM nodes werden erzeugt
- DOM nodes werden geloescht
- DOM nodes werden mit `replaceChild` ausgetauscht
- Arrays kommen in `script.js` und `watchlist.js` vor
- 3 Seiten: `index.html`, `watchlist.html`, `info.html`
- einfache Funktionen ohne Frameworks

## Starten

`index.html` im Browser oeffnen.

Optional:

```bash
python3 -m http.server 8080
```

Danach:

```text
http://localhost:8080
```
